## 📌 About BridgeWorks

**BridgeWorks** is a next-generation single-page enterprise web application designed to connect workforce operations, financial control, and personal productivity into a clean, modern interface. 

Instead of juggling separate apps for accounting, HR management, and team communication, BridgeWorks unifies everything into **3 core operational modules**:

---

## ⚡ Operational Modules

### 1. 🏦 Finance & Accounting
* **Double-Entry Ledgers & Journal Entries**: Complete general ledger, automated debit/credit balancing, trial balance, P&L, and balance sheet.
* **GST Compliance Center**: Real-time GSTR-1 & GSTR-3B liability reports, Input Tax Credit (ITC) utilization tracking, and tax health diagnostics.
* **Bank Reconciliation Engine**: Statement CSV import, automated transaction rule matching, and exception handling.
* **Accounts Payable & Receivable**: Pending expense approvals, vendor management, and COD remittance tracking.

### 2. 👥 HR & Team Operations
* **Master Workforce Register**: Centralized employee directory, department structures, and role permissions.
* **Attendance & Regularizations**: Daily check-ins, geofence verification, shift logs, and regularization approval queues.
* **Payroll Disbursement**: Monthly payroll runs, salary breakdown, statutory deductions, and downloadable employee payslips.
* **Recruitment Pipeline**: Job postings, applicant tracking, and hiring stage management.

### 3. 🗂️ My Desk (Personal Workspace)
* **Personal Notes Knowledge Base**: Rich-text notes editor, quick capture, and tag organization.
* **Task Manager**: Interactive Kanban boards and list views with real-time status updates.
* **Team Chat & Direct Messaging**: Public workspace channels (`#general`, `#finance-compliance`) and instant messaging.
* **Work Diary & Expenses**: Activity logbook and employee expense claim reimbursement.

## 🛠️ Tech Stack

* **Frontend**: React 18, Vite, Material UI (MUI v5), React Router DOM v6
* **Backend**: Python 3.13, Django 5.x, Django REST Framework, SQLite / PostgreSQL
* **Realtime**: WebSockets & Django Channels

---

## 🚀 One-Command Launch (Backend + Frontend + Database)

To launch the entire platform (database migrations, data seeding, Django backend, and Vite frontend) simultaneously, open a terminal in the project root and run:

```bash
npm run bridgeworks
```

*(Alternatively, you can run `npm start` or `npm run dev`)*
